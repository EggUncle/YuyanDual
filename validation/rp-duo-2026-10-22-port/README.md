## 环境

Retroid Pocket Duo，Android 16 / API 36。上屏 display 0，横向 1920 × 1080、369 dpi；下屏 display 2，1280 × 960、320 dpi。固件设置 `ime_fixed=0`、`ime_show_on_second=1` 保持不变。

测试应用为仓库内 `:imeprobe`，不联网、不申请权限、不保存输入。所有截图仅含临时测试文本；密码测试使用临时字符，只显示遮蔽内容和长度。

| 检查 | 观测结果 |
| --- | --- |

## 限制与后续验证

本轮没有逐项验证固定主屏/副屏模式、异常断屏、外接键盘、多外接屏、长时间休眠、长期稳定性，以及所有第三方应用。中文 QWERTY、双拼、手写和剪贴板未在本次恢复版本逐项回归。来源 APK 文档中的其他测试结论不能代替本记录。

密码英文仍保留上游组合行为：第一次 Done 提交组合串，第二次才通知编辑器；本次确认了该现象，没有修改其行为。

当前 GitHub Actions 使用 Android 默认 debug 签名，没有持久化测试 keystore。不同运行产生的 APK 不能保证同包名覆盖安装。持续分发前应配置稳定签名；遇到签名不一致，不应直接卸载有用户数据的输入法。
